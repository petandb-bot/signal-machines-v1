# Phase 2A — original DSP audit before implementation

Base: main abf0634 / v0.18.0. Phase 1 PR #13 remains unmerged; its JSON is a test fixture only. No Phase 1 application or workflow changes are imported.

Read DRONE, PARTIAL, RESON, ALLOY, FRICTION, CHORUS, LEVEL, OUTPUT and their routing/parameter/mode interfaces. `audit-dsp-character.mjs` exercises original classes, both 44.1/48 kHz, macro corners, sustained sources, four closely spaced strikes and release, quiet stereo input and silence. Raw measurements are in audit.json. These limited tests do not identify every aliasing product or establish perceptual quality.

- DRONE already has six phase-continuous oscillators, seeded slow wander, detune proportional to SPREAD² and second/fourth harmonic Nyquist fades. It is not devoid of motion. Its harmonic amplitudes are tied together by COLOR; there is no independent slow redistribution of harmonic energy.
- PARTIAL has 32 oscillators, smooth activation edges, Nyquist attenuation and energy normalization. MASS/WARP act across the bank; once these and PITCH settle, each partial's relative amplitude/frequency settles. This is an opportunity for an optional new character, not evidence of a defect in the original voice.
- RESON already smooths MATERIAL/PITCH into a six-mode TPT bank, changes per-mode decay with material and bounds modal states. Its 110 Hz default and noninteger ratios are intentional. No demonstrated instability warrants changing this legacy response.
- ALLOY already has four independent voices, envelope-shaped FM index, index reduction near Nyquist and character-specific ratios/feedback. The index guard is not a mathematical guarantee that every FM sideband is bandlimited. A measured high-rate reference/spectral-null study is still needed before changing those characteristics or adding oversampling. Retain the current SOFT/METAL/ROUGH voices.
- FRICTION already derives texture from surface distance and uses four integration substeps plus a DC blocker. Do not replace its state response with random texture.
- CHORUS uses smooth moving short reads. Its motion and source overlap must be distinguished from unwanted clicks; no broad rewrite justified by this audit.
- LEVEL links stereo compression, has no makeup gain and rejects invalid input. Its nominal 0 dB position is 1/3. OUTPUT's classic .995 DC pole has a sample-rate-dependent low cutoff (~35 Hz at44.1k /38 Hz at48k). WIDE already supplies a much lower, rate-scaled pole. Changing the classic pole would alter old presets; leave it intact and document the distinction.

Decision: introduce opt-in LIVING candidates for DRONE and PARTIAL only. All original class files remain byte-identical. Keep old frequency-mode values and missing mode on the exact legacy path. Use the existing mode dropdown with three additional `LIVING … Hz` choices per instrument, preserving independent frequency choices without another UI field or slider. New processing lives in separate classes; finite transition mixing is confined to the two instrument adapters. New states are bounded, seeded and coupled to neighboring partial energy. No audio noise, global saturation or oversampling is added.

Acceptance: original-class PCM vs adapter at both rates; all42 existing preset PCM traces; bounded/deterministic new modes, 30/120s WAV comparisons, macro corners, sweep continuity, live mode changes, schema/snapshot and measured buffer/CPU overhead. Human listening and physical iPhone Safari remain unverified; candidates stay unmerged until evaluated. New-mode musical improvement cannot be concluded from spectral movement alone.
